「GitHubも学んだ、Claude Codeも触った。でも、実際に何か作って公開できてない…」

そんな方のための、個人開発の実践体験会です。
一緒に手を動かしながら、AIツールを使ったWebアプリ・サイト制作から公開までの流れを体験しましょう。

## やること

- Claude Code / Cursor を使ってWebアプリ・サイトを作る
- GitHubと連携してWeb公開するまでを一気に体験
- prod / devブランチの使い分け（個人開発ver.）
- 作り込み中のエラー・トラブルの切り分けの考え方
- 差し戻し方法、APIキー管理など実用的なTips
- 開発環境の構築

## やらないこと

- manusによるバイブコーディング
- 今回は完全にローカル（手元のPCで）開発します
- スマホアプリ開発（ウェブアプリを扱います）
- チーム開発の運用や難しい設計の話

## 対象者

- 開発初心者から次のステップへ進みたい方
- Git/GitHub講座・Claude Code講座を受けたことがある
- 個人でWebアプリ・サイトを作りたいけど実践できていない
- 学んだことを「実際に動くもの」に繋げたい

形式：作業会スタイル（手を動かしながら進めます）  
前提知識：GitやGitHub、AIコーディングツールを少し触ったことがある方
